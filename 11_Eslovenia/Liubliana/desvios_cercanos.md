# 🗺️ Desvíos desde Liubliana

## ⭐ Škofja Loka — Prioridad MEDIA (cero fricción)

- **Qué:** pueblito medieval muy lindo cerca de Liubliana.
- **Fricción:** baja (ideal si quieren algo suave).

## ⭐ Velika Planina — Prioridad MEDIA (si el clima acompaña)

- **Qué:** meseta alpina con cabañas tradicionales (vistas + caminata fácil).
- **Fricción:** media (requiere logística + depende del clima).
